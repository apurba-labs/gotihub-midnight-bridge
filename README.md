# GotiHub Midnight Bridge 🚀

### **The Confidential Mutex for Enterprise Governance**

GotiHub Midnight Bridge is a high-performance **Zero-Knowledge (ZK) Sidecar** designed to bring private, immutable governance to the Laravel ecosystem. Built with **Compact** and **Bun**, it acts as a cryptographic shield for high-value organizational approvals.

## 🏗 Architecture
- **Brain:** Laravel IAM / Approval Engine (Business Logic)
- **Shield:** Midnight Network (Confidential Truth Layer)
- **Bridge:** Bun + Midnight SDK (The ZK-Proof Generator)

## 🛠 Tech Stack
- **Language:** Compact (ZK-Smart Contracts)
- **Runtime:** Bun (Fastest TS/JS Runtime)
- **Blockchain:** Midnight Network (Kūkolu Phase)

## 🚀 Getting Started
1. **Compile Circuits:** `compact compile circuits/governance.compact circuits/output`
2. **Setup Env:** Add `MANAGER_SECRET_KEY` to your environment.
3. **Run Bridge:** `bun run bridge.ts`

## 🔒 Security
This bridge implements **Local Witness Generation**. Private keys never leave the host environment; only mathematically verifiable proofs are submitted to the ledger.
